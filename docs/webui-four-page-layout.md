# WebUI 四页布局与稳定性验证（2026-11-19）

## 参考图驱动的视觉迭代

用户提供了 Oh My Keymint 与 Hybrid Mount 截图作为视觉参考。本批借鉴状态主卡、双列指标、低亮度分组卡片、左右对齐的数据行与悬浮胶囊导航；没有引入参考产品的业务功能，也不宣称复刻其源码、Monet 壁纸取色或液态玻璃效果。

- 首页增加蓝灰渐变状态卡与无线波纹装饰，标题来自当前操作/热点状态；配置带宽与客户端实际协商带宽分开表述，未知运行带宽显示待确认。
- 两列卡片展示 6GHz 就绪情况与配置带宽；下方保留热点和 6GHz 操作，再提供紧凑网络/适配/密码状态。
- 深色使用黑底、蓝灰卡片和浅蓝强调色，浅色保留白卡与蓝色强调；控件继续使用 Miuix。
- 底部导航收窄为居中悬浮胶囊，选中项有填充背景，保留 Tab 语义；列表底部保留足够滚动空间。
- 配置及控制项目增加有含义的图标，主要卡片统一边距和圆角。固定命令、后端与恢复逻辑未改。

本轮生产 Wasm 与字体构建通过；33 项逻辑测试沿用未变化代码的通过结果（Gradle up-to-date）。更新热点点击位置与悬浮导航坐标后，24 个 Chromium 场景全部通过，包含 360/393/412/1180 宽度、深浅色、状态失败、活动中禁用、弹窗保存和六轮触摸滚动；人工核对了最终深浅色首页及配置截图。最终 webroot 树哈希为 `8c9ac14d270f2361d205f409d367d0f8e6c4d23f08730ec4005d34df918553eb`。仍未安装到手机。

## 当前批次

源码维护分支为 `ui-stability-20261119`，原 `main` 保留。原本地四页界面及跨启动恢复修改先独立提交，再补充本批改进；没有安装到手机，也没有更新 Release 安装包。

- 首页先显示热点与 6GHz 操作，再显示压缩后的无线概览；详细 6GHz 状态卡移到诊断页。
- 四页均显示操作阶段，操作期间切页不会重新发起操作，配置控件保持禁用。
- 状态读取失败时诊断页仍提供日志入口，关于页保持可访问。
- 连续刷新复用正在执行的查询，避免堆积；桥接异常转换为失败，不泄露异常中的命令内容；关闭日志弹层取消旧的等待，重新打开不会被旧响应覆盖。取消等待不等于终止设备命令。
- `result=ok` 与非零退出码冲突时明确显示失败；不能把成功标记覆盖到异常退出上。
- 关于页许可证指向稳定的 `main`，README 源码地址切换到新分支。
- 新分支 CI 增加 JDK 21 / Gradle 9.2.1 的 JVM 测试和生产 Wasm 编译。

## 本批验证

- JDK 21、Gradle 9.2.1，`jvmTest` 共 33 项通过；生产 Wasm 构建及字体子集生成通过。
- Chromium 159 + 模拟 KernelSU 桥共 24 个场景通过。包括导航不发写命令、迁移阻塞、启停、联网等待失败、启动拒绝、名称/密码/带宽保存、活动状态禁止改名、操作中切页、状态失败页、六轮触摸往返滚动。
- 截图覆盖 360×800、393×852、412×892、1180×820，以及深浅色；人工检查了首页、配置页、运行中配置禁用与弹窗。浏览器检查仍有坐标依赖，不替代 Android WebView、软键盘及无障碍工具验收。
- 生命周期离线测试 5 项通过；原生 wrapper 契约 18 项通过，新增跨启动原厂确认和 init 配置不符拒绝场景。
- 主机全套首次运行 586 项：522 通过、56 跳过、8 个缺 Clang 的环境错误；安装 Clang 18 后仅复测受影响的 MLO/TWT 套件，8 项均通过，另 1 项仍按缺私有样本跳过。合并结果为 530 项通过、56 项跳过，无未解决失败；不是再跑一次全套的结果。
- Wasm 输出仍约 3.63 MiB，Skiko 约 8.25 MiB，webpack 有体积提示；本批不据桌面加载时间推断手机启动性能。

本批未调用 ADB，没有无线、客户端联网或 Android WebView 真机验证。字体输入必须齐备 Regular/Medium/Bold，Ubuntu 基础字体包可能缺 Medium，见模块构建说明。
